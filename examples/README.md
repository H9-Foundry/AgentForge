# Examples

## Included Examples

- `sample-repo/`
  - a minimal standalone repository shape for trying the local `pr-review` workflow outside the monorepo
- `custom-agent-template/`
  - a starter custom agent package showing the minimum manifest and implementation shape
  - includes registration and policy examples for an allowed local plugin and a blocked plugin

Fixture-style repositories used by tests still live inside package test suites so the automated suite stays deterministic.
